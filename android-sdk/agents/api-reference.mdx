abbreviated. Source of truth: the generated reference and the binary API dumps of the release you use.

Markdown URL scheme (Dokka escapes uppercase letters as `-` followed by the lowercase letter):

- `<module>` is the Gradle path: `core`, `compose`, `gradle-plugin`.
- `<-module>` is the escaped module title: `-core`, `-compose`.
- `<package>` is literal: `io.tolgee`, `io.tolgee.storage`, `io.tolgee.model`, `io.tolgee.common`.
- `<-type>` escapes the class name: `Tolgee` → `-tolgee`, `TolgeeContextWrapper` → `-tolgee-context-wrapper`,
  nested `Tolgee.Config.ContentDelivery.Builder` → `-tolgee/-config/-content-delivery/-builder`.
- Members are sibling files: `.../-tolgee-android/t-plural.md`, `.../-tolgee/set-locale.md`.

Examples: [`Tolgee`](https://tolgee.github.io/tolgee-mobile-kotlin-sdk/markdown/core/-core/io.tolgee/-tolgee/index.md),
[`TolgeeAndroid`](https://tolgee.github.io/tolgee-mobile-kotlin-sdk/markdown/core/-core/io.tolgee/-tolgee-android/index.md),
[compose helpers](https://tolgee.github.io/tolgee-mobile-kotlin-sdk/markdown/compose/-compose/io.tolgee/index.md).

## Module `core` (`io.tolgee.mobile-kotlin-sdk:core`)

### `io.tolgee.Tolgee` (common)

| Member | Purpose |
|---|---|
| `Tolgee.init { … }` / `Tolgee.init(config)` | Create the singleton. Call once at app start. |
| `Tolgee.new { … }` | Create an independent instance (tests, DI) without touching the singleton. |
| `Tolgee.instance` / `Tolgee.instanceOrNull` | The singleton (`TolgeeAndroid` on Android); `instanceOrNull` is null before `init`. |
| `Tolgee.systemLocale` | Device locale. |
| `t(key)` / `t(key, params: TolgeeMessageParams)` | Immediate lookup; `null` until the locale is loaded or when the key is missing. |
| `tFlow(key)` / `tFlow(key, params)` | `Flow<String>` that loads on collection and re-emits on locale/translation changes. |
| `tArray(key)` / `tArrayFlow(key)` | String-array keys. |
| `suspend preload()` / `suspend preloadAll()` | Load manifest and current locale / every published locale. |
| `setLocale(tag)` / `setLocale(locale)` / `getLocale()` | Locale flow; `setLocale` does not fetch by itself. |
| `availableLocales` / `availableLocaleTags` | From config or the CDN manifest; `null` before `preload`. |
| `changeFlow` | `MutableSharedFlow<Unit>` emitting after manifest and translation loads. |
| `addChangeListener` / `removeChangeListener` | Callback alternative to `changeFlow` (main thread). |
| `config` | The immutable `Tolgee.Config`. |

### `io.tolgee.Tolgee.Config.Builder`

| Builder call | Meaning |
|---|---|
| `locale(tag/locale)` | Initial locale; default: system locale. |
| `availableLocaleTags(vararg)` / `availableLocales(...)` | Published locales; replaces the manifest lookup. |
| `defaultLanguage(tag/locale)` | Last fallback when the resolved locale is not available. |
| `network { … }` | Custom Ktor `HttpClient` (`client(...)`) and `CoroutineContext` (`context(...)`). |
| `contentDelivery { … }` / `contentDelivery(url) { … }` | See below. |

### `io.tolgee.Tolgee.Config.ContentDelivery.Builder`

| Property / call | Default | Meaning |
|---|---|---|
| `url` | `null` | Content Delivery URL prefix. Without it nothing is fetched. |
| `path` | `{ "$it.json" }` | Language tag → file path under `url`. |
| `manifestPath` | `path("manifest")` → `manifest.json` | Optional list of locales. |
| `storage` | `platformStorage` (Android: none until you set `TolgeeStorageProviderAndroid`) | Persistent cache. |
| `formatter` | `Tolgee.Formatter.Sprintf` | `Sprintf` for `%1$s` placeholders, `ICU` for `{name}` messages. |
| `maxLocalesInMemory` | `1` | LRU size for loaded locales; `null` = unlimited. |

`Tolgee.Formatter` is a sealed interface with objects `Sprintf` and `ICU`.
`TolgeeMessageParams` (package `io.tolgee.model`) has `None`, `Indexed(vararg args)` (Sprintf and ICU) and
`Mapped(map)` (ICU only).

### `io.tolgee.TolgeeAndroid` (Android; what `Tolgee.instance` is)

| Member | Purpose |
|---|---|
| `t(context, @StringRes id)` / `t(context, id, vararg args)` / `t(resources, …)` | Lookup by resource id with bundled fallback. |
| `tFlow(context, id[, args])` | Reactive variant. |
| `tPlural(resources, @PluralsRes id, quantity[, args])` / `tPluralFlow(...)` | Plurals. |
| `tArray(resources, @ArrayRes id)` / `tArrayFlow(...)` | Arrays. |
| `tStyled(...)`, `tPluralStyled(...)`, `tArrayStyled(...)` | `CharSequence` variants keeping markup. |
| `preload(lifecycleOwner)` / `preloadAll(lifecycleOwner)` | Launch loading in `lifecycleScope`, returns `Job`. |
| `retranslate(activity)` / `retranslate(rootView)` | Re-apply translations to views inflated through the wrapper. |
| `TolgeeAndroid.getKeyFromResources(context|resources, id)` | The key name used for a resource id. |

### `io.tolgee.TolgeeContextWrapper` (Android)

| Member | Purpose |
|---|---|
| `TolgeeContextWrapper.wrap(base)` / `wrap(base, tolgee)` | Wrap an Activity (or any) context; plain wrapper when Tolgee is not initialized. |
| constructor flags `interceptGetString`, `interceptGetText`, `argumentLayoutInflater` | Fine-grained control when constructing directly. |

The wrapper's `Resources` overrides `getString`, `getText`, `getQuantityString`, `getQuantityText`, `getStringArray`,
`getTextArray`; its `LayoutInflater` translates `android:text`, `android:hint` and `android:contentDescription`.

### `io.tolgee.common` extension functions (Android)

`Context.getStringT(id[, args])`, `Resources.getStringT(...)`, `Resources.getQuantityStringT(id, quantity[, args])`,
`Resources.getStringArrayT(tolgee, id)`, `Context.getTextT(tolgee, id)`, `Resources.getTextT(tolgee, id[, def])`,
`Resources.getQuantityTextT(tolgee, id, quantity)`, `Resources.getTextArrayT(tolgee, id)`. Overloads without a
`tolgee` parameter use `Tolgee.instanceOrNull` and fall back to the plain resource.

### `io.tolgee.storage`

| Type | Purpose |
|---|---|
| `TolgeeStorageProvider` | Interface `get(name): ByteArray?` / `put(name, data)` for persistent caching. |
| `TolgeeStorageProviderAndroid(context, versionCode, path = "tolgee/localization-cache")` | File cache under `filesDir`, keyed by version code. |

## Module `compose` (`io.tolgee.mobile-kotlin-sdk:compose`)

All in package `io.tolgee`; every function has an overload with an explicit `tolgee: Tolgee` first parameter.

| Composable | Android | Compose Multiplatform |
|---|---|---|
| `stringResource(id[, vararg args])` | `@StringRes Int` | `StringResource` (`Res.string.x`) |
| `pluralStringResource(id, quantity[, vararg args])` | `@PluralsRes Int` | `PluralStringResource` |
| `stringArrayResource(id)` | `@ArrayRes Int` → `Array<String>` | `StringArrayResource` → `List<String>` |
| `Tolgee.setLocale(composeLocale)` / `Config.Builder.locale(composeLocale)` | `androidx.compose.ui.text.intl.Locale` overloads | same |

Behaviour: collect `tFlow` as state with the bundled resource as initial value; without an initialized `Tolgee`
they delegate to the platform composable.

## Module `gradle-plugin`

Published as `io.tolgee.mobile-kotlin-sdk:gradle-plugin`, but the compiler plugin it configures is disabled in the
current release; do not add it to consumer builds.
