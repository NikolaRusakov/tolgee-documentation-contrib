**Outcome:** the app builds, `getString()` and XML layouts resolve through Tolgee, one string visibly comes from
the Content Delivery CDN, and bundled `strings.xml` remains the offline fallback.

This recipe targets apps that use Activities and XML layouts (with or without Fragments, ViewBinding or DataBinding).
For Jetpack Compose screens use [Install: Jetpack Compose](./install-compose.mdx); both can coexist in one app.

## Prerequisites

- Android app with `minSdk >= 21`, Kotlin, Gradle with Kotlin DSL or Groovy (both work; examples use Kotlin DSL).
- A Tolgee project whose keys match your `strings.xml` names. If the project is empty, push the strings first with the
  [Tolgee CLI](/tolgee-cli/installation) using `format: "ANDROID_XML"` (config example in
  [Starters: Android Views](../integrate/AndroidViews.mdx)).
- A Content Delivery created in **Tolgee Platform → Project → Developer settings → Content Delivery** with format
  **Android SDK**. Copy its URL prefix, e.g. `https://cdn.tolg.ee/2b0b7c...`. See
  [Content Delivery](/platform/projects_and_organizations/content_delivery).
- The list of locales published there (for example `en`, `cs`, `fr`).

Nothing secret is needed at runtime: the CDN URL is public. Tolgee API keys are only used by the CLI.

## Detect the project

Run these before editing; the results decide the exact edits below.

```bash
# Build scripts and version catalog
ls gradle/libs.versions.toml app/build.gradle.kts app/build.gradle 2>/dev/null
grep -nE 'minSdk|compileSdk|buildConfig' app/build.gradle* | head
# Application subclass (create one if none is registered)
grep -rn 'android:name=' app/src/main/AndroidManifest.xml | head -3
grep -rln ': Application()' app/src/main | head -3
# Activities that must wrap their context
grep -rln 'Activity()' app/src/main --include='*.kt' --include='*.java'
# Existing network security config
grep -n 'networkSecurityConfig' app/src/main/AndroidManifest.xml; ls app/src/main/res/xml/ 2>/dev/null
# Is the SDK already present?
grep -rn 'io.tolgee' gradle/libs.versions.toml app/build.gradle* 2>/dev/null
```

Resolve the SDK version from
[Maven Central](https://central.sonatype.com/search?namespace=io.tolgee.mobile-kotlin-sdk) (current release:
`1.0.0-alpha04`).

## Steps

### 1. Add the dependency

With a version catalog:

```toml title="gradle/libs.versions.toml"
[versions]
tolgee = "1.0.0-alpha04"

[libraries]
tolgee-core = { group = "io.tolgee.mobile-kotlin-sdk", name = "core", version.ref = "tolgee" }
```

```kotlin title="app/build.gradle.kts"
dependencies {
    implementation(libs.tolgee.core)
}
```

Without a catalog: `implementation("io.tolgee.mobile-kotlin-sdk:core:1.0.0-alpha04")`. Make sure `mavenCentral()` is in
`dependencyResolutionManagement.repositories` (it is in every default Android project).

Enable `BuildConfig` if the module has it disabled, because the cache is keyed by `BuildConfig.VERSION_CODE`:

```kotlin title="app/build.gradle.kts"
android {
    buildFeatures { buildConfig = true }
}
```

### 2. Allow the CDN hosts

Create the network security config (or add the two domains to an existing one):

```xml title="app/src/main/res/xml/network_security.xml"
<?xml version="1.0" encoding="utf-8"?>
<network-security-config xmlns:android="http://schemas.android.com/apk/res/android">
    <domain-config>
        <domain includeSubdomains="true">tolgee.io</domain>
        <domain includeSubdomains="true">tolg.ee</domain>
        <!-- self-hosted or custom CDN: add its host here -->
    </domain-config>
</network-security-config>
```

```xml title="app/src/main/AndroidManifest.xml"
<uses-permission android:name="android.permission.INTERNET" />

<application
    android:name=".MyApplication"
    android:networkSecurityConfig="@xml/network_security"
    ...>
```

### 3. Initialize once in the Application class

```kotlin title="app/src/main/java/.../MyApplication.kt"
import android.app.Application
import io.tolgee.Tolgee
import io.tolgee.storage.TolgeeStorageProviderAndroid

class MyApplication : Application() {
    override fun onCreate() {
        super.onCreate()
        Tolgee.init {
            contentDelivery {
                url = "https://cdn.tolg.ee/your-cdn-url-prefix" // Content Delivery, format "Android SDK"
                // Persistent cache; a new app version starts with an empty cache.
                storage = TolgeeStorageProviderAndroid(this@MyApplication, BuildConfig.VERSION_CODE)
                // Locales published in the Content Delivery. Optional when the CDN serves manifest.json,
                // required for BCP 47 fallback (en-US -> en) otherwise.
                availableLocaleTags("en", "cs", "fr")
            }
            // Used when the device locale is not published.
            defaultLanguage("en")
        }
    }
}
```

Defaults that are correct for Android XML strings and therefore not written above: `path = { "$it.json" }` (the file
layout of the "Android SDK" delivery format) and `formatter = Tolgee.Formatter.Sprintf` (`%1$s`, `%d` placeholders).
Only set `formatter(Tolgee.Formatter.ICU)` if the delivery uses ICU placeholders.

### 4. Wrap the context of every Activity

This makes `getString`, `getText`, `getQuantityString`, `getStringArray` and layout inflation (`android:text`,
`android:hint`, `android:contentDescription`) resolve through Tolgee, with automatic fallback to the bundled resource.

```kotlin title="MainActivity.kt"
import android.content.Context
import io.tolgee.TolgeeContextWrapper

class MainActivity : AppCompatActivity() { // or Activity / ComponentActivity
    override fun attachBaseContext(newBase: Context?) {
        super.attachBaseContext(TolgeeContextWrapper.wrap(newBase))
    }
}
```

If the app has a `BaseActivity`, add the override there once. Fragments inherit the wrapped context through
`requireContext()`.

### 5. Load translations and react to changes

```kotlin title="MainActivity.kt"
import androidx.lifecycle.lifecycleScope
import io.tolgee.Tolgee
import kotlinx.coroutines.launch

override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    setContentView(R.layout.activity_main)

    lifecycleScope.launch {
        Tolgee.instance.changeFlow.collect {
            // Cheapest: re-apply translations to inflated views in place.
            Tolgee.instance.retranslate(this@MainActivity)
            // Strings set from code with format arguments must be set again here.
            bindDynamicStrings()
            // Alternative for complex screens: recreate()
        }
    }
}

override fun onStart() {
    super.onStart()
    Tolgee.instance.preload(this) // fetch current locale; emits changeFlow when data arrives
}
```

### 6. (Optional) Expose a language switch

```kotlin
Tolgee.instance.setLocale("cs")        // BCP 47 tag or java.util.Locale
Tolgee.instance.preload(this)          // load the new locale; UI updates through changeFlow
```

## Verify

1. The CDN serves JSON for a published locale (replace the prefix):

   ```bash
   curl -sSf "https://cdn.tolg.ee/your-cdn-url-prefix/en.json" | head -c 300
   ```

   Expected: HTTP 200 and a JSON object such as `{"welcome_message":"Welcome","items_count":{"one":"…","other":"…"}}`.
   A 403/404 means the prefix is wrong or the delivery is not published.

2. The project builds:

   ```bash
   ./gradlew :app:assembleDebug
   ```

3. Run the app. Change a translation in Tolgee Platform (publish the delivery if auto-publish is off), restart the app
   or trigger `preload`, and confirm the new text appears without a new APK. The CDN caches for up to 15 minutes.

4. Call `Tolgee.instance.setLocale("cs")` followed by `preload(activity)`; text inflated from layouts changes in place.

Done means: build green, one string observed from the CDN, and a locale switch re-rendered without a crash.

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| Only bundled English text is shown | `Tolgee.init` not executed before the Activity was created, or wrong CDN prefix | Initialize in `Application.onCreate()`; verify with the `curl` above |
| `CLEARTEXT communication … not permitted` or SSL errors | Host missing from `network_security.xml` | Add `tolgee.io`, `tolg.ee` or your CDN host and reference the file from the manifest |
| Text in layouts translates, text set from code does not | The code path uses a non-wrapped context (Application, Service, ViewModel) | Use `context.getStringT(R.string.key)` or `Tolgee.instance.t(context, R.string.key, args)` there, or wrap that context with `TolgeeContextWrapper.wrap(context)` |
| Parameterised layout string stays untranslated | The inflater skips strings with placeholders on purpose | Set it from code: `textView.text = getString(R.string.key, arg)` inside `changeFlow` handling |
| Locale switch does nothing | `preload` not called after `setLocale`, or locale not in `availableLocaleTags` | Call `preload(activity)` after switching; list every published locale |
| Translations return but placeholders render literally | Delivery uses ICU placeholders while the SDK formats with Sprintf | Match them: `formatter(Tolgee.Formatter.ICU)` or export with Android/Java placeholders |

More cases: [Diagnostics](./diagnostics.mdx).
