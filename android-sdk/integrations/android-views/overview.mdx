Tolgee Android SDK supports classic Android apps built with Activities, Fragments, XML layouts and ViewModels through
the `io.tolgee.mobile-kotlin-sdk:core` artifact. You initialize Tolgee once in the Application class and wrap the
context of each Activity. From then on `getString`, `getQuantityString`, `getStringArray` and layout attributes such
as `android:text` resolve through Tolgee, with the bundled resource as fallback, and a `Flow` API keeps text that is
set from code up to date.

<StarterBanner starter="android-views" label="Android Views" />

## What does the core artifact give a Views app?

- **`TolgeeContextWrapper`**: wraps an Activity context so every resource lookup and every inflated layout is
  translated, without touching call sites.
- **`tFlow`, `tPluralFlow`, `tArrayFlow`**: `Flow<String>` variants for text you set from code with arguments, so a
  language switch or a published translation updates the view in place.
- **`changeFlow` and `retranslate`**: one signal when translations change, and one call that re-applies them to a
  whole Activity without `recreate()`.
- **`preload`**: fetches the current language when a screen starts, cache first, then CDN.
