Tolgee Android SDK supports Jetpack Compose and Compose Multiplatform through the
`io.tolgee.mobile-kotlin-sdk:compose` artifact, which includes `core`. You initialize Tolgee once in the Application
class and replace three imports: `stringResource`, `pluralStringResource` and `stringArrayResource` from `io.tolgee`
instead of `androidx.compose.ui.res`. Call sites stay identical, composables recompose when translations or the
language change, and previews keep working through the built-in fallback.

<StarterBanner starter="jetpack-compose" label="Jetpack Compose" />

## What does the compose artifact give a Compose app?

- **Drop-in helpers** with the same signatures as the Compose originals, so a migration is an import change.
- **Reactivity for free.** Each helper collects `tFlow` as state, with the bundled resource as initial value, so a
  language switch recomposes every text without any wiring.
- **Fallback in previews and tests.** When `Tolgee` is not initialized, the helpers delegate to the platform composable.
- **Explicit instance overloads** for apps that inject a `Tolgee` instance instead of using the singleton.
- **Compose Multiplatform** support with `Res.string.*` and `Res.plurals.*` resources.
