Tolgee Android SDK changes the language of a Jetpack Compose app at runtime with one call, `setLocale`. Every text
rendered by the `io.tolgee` helpers recomposes on its own, because each helper collects `tFlow` as state. A locale
switcher composable therefore needs no manual reload: it observes the current language through `changeFlow` and calls
`setLocale` on click. This page is for anyone adding a language switch to a Compose screen.

## Build a locale switcher

The demo app's switcher renders one segmented button per language. Each click calls `setLocale`, and
`isLocaleSelected` observes `changeFlow` so the active language stays highlighted. Language names are deliberately not
translated. Call the button once per language, for example with `en`, `cs` and `fr`.

`setLocale` accepts a BCP 47 tag, a `java.util.Locale`, or a Compose `androidx.compose.ui.text.intl.Locale`. The
language is process-wide and not persisted by Tolgee Android SDK; store the tag in your preferences and pass it to
`Tolgee.init` with `locale(tag)` if the app should remember it.

## Observe the current language

`changeFlow` emits after the manifest loads and after every translation load. Mapping it to `getLocale()` and
collecting it as state gives a composable that recomposes whenever the language changes, which is useful for a header,
a flag icon or analytics.

```kotlin
@Composable
fun CurrentLanguage() {
    val tolgee = Tolgee.instance
    val locale by tolgee.changeFlow.map { tolgee.getLocale() }.collectAsState(initial = tolgee.getLocale())
    Text(locale.language)
}
```

## Choose the languages to offer

The languages published in the Content Delivery, which Tolgee Android SDK knows from `availableLocaleTags` in
`Tolgee.init` or from the delivery's `manifest.json`. Build the switcher from `Tolgee.instance.availableLocaleTags`
when the list should follow the platform instead of being hard-coded.

## Understand language fallback

Tolgee Android SDK resolves a locale progressively: `zh-Hans-CN` falls back to `zh-Hans`, then `zh`, then to
`defaultLanguage` from `Tolgee.init`. A device set to `en-US` receives the `en` translations. When a key is missing in
the resolved language, the helper returns the bundled Android resource for the device configuration. The rules are on
[Language and fallback](/android-sdk/language).
